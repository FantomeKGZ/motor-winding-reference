# Границы проекта

Этот репозиторий предназначен для разработки **внешнего сайта справочника** и связанных с ним инструментов.

## Что входит в этот проект

- привычный справочник обмотчика в desktop- и mobile-представлении;
- поиск и навигация по справочнику;
- внешняя карточка двигателя;
- отображение схем укладки и схем соединения;
- внешний интерфейс генератора перерасчёта;
- внешний интерфейс склада проводов;
- интеграционный слой для чтения данных с ESP32;
- документация по форматам обмена с CoilMaster/ESP32.

## Что не входит

- прошивка ESP32;
- веб-сайт, физически размещённый на ESP32;
- обмен ESP32 ↔ Arduino;
- драйверы microSD, RTC, Wi‑Fi и периферии ESP32;
- изменение рабочих данных на ESP32 без явно согласованного API.

## Главное правило

Оригинальные каталоги `sourse/desktop` и `sourse/mobile` считаются эталонными исходниками и не редактируются. Новый код создаётся в `site/`, `tools/` и `docs/`.

## Совместимость интерфейса

Привычный сценарий работы старого справочника имеет приоритет над визуальной модернизацией. Цвета и техническая оболочка могут обновляться, но расположение ключевых элементов, логика поиска схем и структура основных страниц должны оставаться узнаваемыми.
