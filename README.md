# CoilMaster Motor Winding Reference

Дополнительный статический справочник для CoilMaster по обмоткам асинхронных электродвигателей.

## Новая структура

```text
index.html                 единая responsive-точка входа
assets/site.css            дизайн новой оболочки
assets/site.js             поиск по полному исходному индексу
reference/                 канонический полный справочник
reference/documents/style.css
                           общий responsive-стиль всех старых страниц
```

Отдельные desktop/mobile сайты больше не нужны: один и тот же `reference/` используется на ПК, планшете и телефоне.

## Сохранность данных

Каноническим источником выбран полный desktop-экспорт от 09.12.2024. Перед консолидацией оба исходных дерева были сравнены средствами Git:

- абсолютное большинство файлов desktop/mobile байтово идентичны;
- чистый tree diff показал различия только в 5 файлах;
- основная содержательная разница — `index.html`, где mobile-вариант является сокращённым представлением большой desktop-матрицы;
- отдельная проверенная страница схемы и общий CSS имели одинаковые blob SHA в обеих версиях.

Поэтому полный desktop-экспорт сохранён как `reference/`, а responsive-поведение реализуется дизайном, а не второй копией данных.

## Поиск

Новая главная страница загружает `reference/index.html`, декодирует исходный Windows-1251 и строит каталог из фактических ссылок. Отдельную базу ссылок поддерживать не требуется: изменения канонического индекса автоматически отражаются в поиске.

## Кодировка исходных материалов

Исторические страницы справочника остаются в `windows-1251`, чтобы не переписывать и не рисковать повреждением большого массива материалов. Новые файлы оболочки (`index.html`, `assets/*`) используют UTF-8.

## Авторство материалов

Технические материалы и изображения сохраняют указанные на исходных страницах сведения об авторстве и источниках. Новая оболочка меняет навигацию и отображение, но не присваивает авторство исходного содержания.

## Локальный запуск

Из корня репозитория можно запустить любой статический HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого открыть `http://localhost:8080/`.

Прямое открытие через `file://` оставляет сами страницы доступными, но браузер может блокировать `fetch`, поэтому динамический поиск на новой главной требует HTTP/HTTPS.
