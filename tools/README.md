# Инструменты анализа справочника

Исходные каталоги `sourse/desktop` и `sourse/mobile` не изменяются.
Скрипты из этой папки читают оригинальные файлы и создают производные отчёты для нового сайта.

## Проверка ссылок и построение индекса

```bash
python tools/build_scheme_index.py \
  --desktop "sourse/desktop/Справочник от 09.12.2024 HTML/index.html" \
  --mobile "sourse/mobile/Справочник от 09.12.2024 для мобильных устройств HTML/index.html" \
  --output site/shared/data
```

Скрипт:

- читает исходные страницы в кодировке Windows-1251;
- извлекает локальные ссылки на HTML-страницы;
- проверяет наличие файлов;
- не изменяет исходники;
- создаёт UTF-8 отчёты:
  - `desktop-links.json`;
  - `mobile-links.json`;
  - `comparison.json`.

Код возврата `0` означает, что битых ссылок не найдено. Код `1` означает, что обнаружены отсутствующие целевые файлы. Код `2` означает ошибку входных путей.

## Правило разработки

Сначала формируется и проверяется индекс. Только после этого ссылки автоматически или вручную переносятся в новые главные страницы. Это защищает привычную навигацию от случайных переходов на отсутствующие материалы.
