# CoilMaster UI 2.0

## Назначение

Единая дизайн-система для справочника, склада проводов, генератора перерасчёта, базы двигателей и веб-интерфейса ESP32.

Главные страницы старого справочника сохраняют привычную компоновку. Новые компоненты применяются вокруг исходного содержимого и на новых рабочих страницах.

## Основные принципы

1. Привычные таблицы и порядок разделов не меняются без необходимости.
2. Desktop и mobile используют одинаковые компоненты, но разную компоновку.
3. Все элементы управления имеют высоту не менее 42 px.
4. Цвет не является единственным способом показать состояние.
5. Справочник должен работать локально и без внешних библиотек.
6. Компоненты должны быть достаточно лёгкими для будущего использования на ESP32.

## Цветовые роли

- `--cm-primary` — основное действие и активные элементы.
- `--cm-accent` — исторический коричневый цвет справочника.
- `--cm-success` — успешная проверка, достаточный складской остаток.
- `--cm-warning` — допустимое отклонение или низкий остаток.
- `--cm-danger` — ошибка, недопустимый расчёт или нехватка материала.
- `--cm-muted` — вторичная информация.

## Базовые компоненты

Компоненты находятся в `site/shared/css/components.css`.

- `.cm-card` — карточка двигателя, расчёта или складской позиции.
- `.cm-grid` — адаптивная сетка карточек.
- `.cm-button` — общая кнопка.
- `.cm-field`, `.cm-input`, `.cm-select` — поля форм.
- `.cm-badge` — короткая метка состояния.
- `.cm-status` — уведомление или предупреждение.
- `.cm-data-list` — список параметров карточки двигателя.

## План применения

1. Не менять внешний вид оригинальной таблицы выбора схем.
2. Применить новые компоненты к стартовой странице выбора интерфейса.
3. Создать тестовую карточку двигателя.
4. Создать общую форму для генератора Al → Cu.
5. Перенести склад проводов на карточки и адаптивную таблицу.
6. После проверки использовать те же компоненты в проекте CoilMaster ESP32.

## Ограничение

Новые стили не должны зависеть от CDN, веб-шрифтов или JavaScript-фреймворков. Это позволит разместить интерфейс на microSD и обслуживать его ESP32.
