# Решения по интерфейсу справочника

## Главный принцип

Главные страницы настольной и мобильной версий должны оставаться узнаваемыми для пользователей старого справочника.

Сохраняются:

- привычная шапка;
- центральная таблица выбора по числу пазов и оборотам;
- порядок основных разделов;
- знакомые названия ссылок;
- отдельные desktop и mobile входные страницы.

Добавляются без разрушения старой логики:

- боковое меню CoilMaster на ПК;
- выдвижное меню на телефоне;
- строка поиска;
- быстрые переходы к базе двигателей, складу проводов и перерасчёту Al → Cu;
- горизонтальная прокрутка таблиц;
- закреплённый первый столбец с числом пазов;
- UTF-8 в новом интерфейсе.

## Ограничения этапа

- каталог `sourse/` является неизменяемым архивом исходников;
- новые страницы создаются только в `site/`;
- ссылки на старые материалы добавляются только после проверки существования файла;
- содержимое и авторские подписи не изменяются при переносе;
- публикация материалов должна учитывать условия правообладателя исходного справочника.

## Текущие маршруты

- `site/desktop/index.html` — настольная главная;
- `site/mobile/index.html` — мобильная главная;
- `site/shared/css/base.css` — общие стили;
- `site/shared/js/navigation.js` — навигация.

## Следующие задачи

1. Автоматически построить перечень файлов desktop и mobile.
2. Проверить соответствие ссылок главных таблиц.
3. Добавить остальные строки таблиц.
4. Определить главные страницы разделов старого справочника.
5. Создать поисковый индекс без дублирования статей.
