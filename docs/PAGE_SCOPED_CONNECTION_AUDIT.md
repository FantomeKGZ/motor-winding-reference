# Аудит неоднозначных схем подключения

Статус: внешний сайт `motor-winding-reference`; ESP32 не изменяется.

## Зачем нужен аудит

Каталог CoilMaster различает два уровня достоверности для схем подключения:

- `scope: "image"` — конкретная картинка надежно связана с конкретным `CM-CON-*`;
- `scope: "page"` — известна реальная `ss*.html` страница, но конкретную картинку безопасно определить пока нельзя.

`scope: "page"` является допустимым и безопасным состоянием. Оно лучше, чем ошибочно показать мастеру неверную звезду, треугольник или специальную схему.

## Инструмент

```text
tools/audit_page_scoped_connections.py
```

Он не изменяет каталог и старые HTML-файлы. Инструмент формирует рабочую очередь для дальнейшего улучшения распознавания.

Для каждой неоднозначной страницы теперь считаются:

- `reference_count` — сколько раз варианты этой страницы используются схемами укладки;
- `scheme_count` — сколько различных `CM-SCH-*` зависят от страницы;
- `option_count` — сколько уникальных page-scoped `CM-CON-*` относится к странице;
- распознанные `types`;
- количество вариантов с неизвестным типом.

Страницы сортируются по приоритету: сначала те, исправление которых улучшит наибольшее количество карточек и вариантов укладки.

## Отчеты CI

```text
site/shared/data/desktop-page-scoped-connection-audit.json
site/shared/data/mobile-page-scoped-connection-audit.json
```

Ключевой массив:

```json
{
  "priority_pages": [
    {
      "page": "ss....html",
      "reference_count": 42,
      "scheme_count": 30,
      "option_count": 2,
      "types": ["star", "delta"]
    }
  ]
}
```

Также отчет показывает долю всех page-scoped ссылок, приходящуюся на первые 10 страниц. Это позволяет оценить, насколько выгодно улучшать несколько самых частых страниц вместо ручной обработки всего архива.

## Правило дальнейшей работы

При улучшении распознавания нельзя автоматически превращать `scope: "page"` в `scope: "image"` только потому, что на странице есть одна или несколько картинок.

Для перехода к `scope: "image"` требуется подтвержденная связь:

```text
подпись/контекст типа подключения
        ↓
конкретная картинка
        ↓
реальная ссылка внутри той же ss*.html
        ↓
детерминированный CM-CON-*
```

Если связь неоднозначна, вариант остается `scope: "page"`.

## Следующий технический этап

После очередной сборки каталога нужно взять первые страницы из `priority_pages` и изучить их реальные HTML-шаблоны. Если несколько частых страниц имеют одинаковую структуру, следует добавить в генератор одно общее надежное правило распознавания вместо набора исключений по именам файлов.

Это особенно важно для будущего виджета карточки двигателя: отсутствие маленького превью допустимо, неверное превью — нет.
