# Аудит старых HTML-страниц

Этот документ фиксирует результаты автоматической инвентаризации исходного справочника. Исходные файлы в `sourse/` не изменяются.

## Итоговые числа

- Desktop: **1856 HTML-страниц**.
- Mobile: **1856 HTML-страниц**.
- Всего проверено: **3712 страниц**.
- Страниц с изображениями: **1852 в каждой версии суммарно 1852 уникальных по структуре страницы на вариант**.
- Общий объём текстового содержимого, извлечённого для инвентаризации: **7 497 694 символа**.
- Практически все рабочие страницы подключают один общий файл `documents/style.css`.
- В исходных страницах не обнаружено значимого массива inline `<style>` или `style="..."`, поэтому основное оформление можно переносить через общий совместимый CSS, не удаляя технический текст.

## Правила модернизации

1. Технический текст не сокращается автоматически.
2. Подписи к схемам, пояснения, формулы и ссылки сохраняются.
3. Изображения не заменяются и не объединяются только по визуальному сходству.
4. Старые страницы остаются эталоном для сравнения.
5. Главная таблица сохраняет исходные строки, столбцы, числа пазов, обороты и ссылки.
6. Верхний старый графический баннер не является частью рабочих данных и в новой оболочке не показывается.
7. Геометрия таблиц должна быть близка к оригинальной: компактные ячейки, исходная ширина по содержимому, без искусственного растягивания на весь экран.

## Вывод

Основная ценность старого сайта находится в HTML-контенте, таблицах, изображениях и связях между страницами. Поэтому модернизация выполняется вокруг существующего содержимого: новая навигация, поиск и Integration Layer добавляются снаружи, а сама рабочая часть справочника сохраняется максимально узнаваемой.
