# Контракт контекста схемы

Этот документ описывает небольшой стандартизированный объект, который внешний сайт формирует из уже существующих страниц справочника. Он нужен для будущего связывания справочника с CoilMaster/ESP32 без `motor_id` и без дублирования изображений и HTML на ESP32.

## Принцип

ESP32 хранит и отдаёт рабочие данные двигателя. Внешний сайт хранит справочник и изображения схем. Связь выполняется через параметры обмотки.

Внешний сайт после загрузки страницы схемы публикует объект `window.CoilMasterSchemeContext` и событие `coilmaster:scheme-context`.

Пример:

```json
{
  "version": 1,
  "source": "legacy-handbook",
  "source_path": "y243000.html",
  "title": "24 паза 3000 об/мин",
  "slots": 24,
  "rpm": 3000,
  "poles": 2,
  "q": 4,
  "phase_start": "1-9-17",
  "raw": {
    "slots": "24",
    "rpm": "3000 об/мин",
    "poles": "2",
    "q": "4",
    "phaseStart": "1-9-17"
  }
}
```

## Поля

- `version` — версия этого контракта.
- `source` — источник данных; сейчас `legacy-handbook`.
- `source_path` — путь исходной HTML-страницы внутри справочника.
- `title` — название страницы.
- `slots` — число пазов, если удалось безопасно извлечь.
- `rpm` — обороты в минуту, если указаны на странице.
- `poles` — значение `2p`, если оно есть.
- `q` — число пазов на полюс и фазу.
- `phase_start` — начало фаз в исходной записи.
- `raw` — исходные извлечённые строки без смыслового преобразования.

Необнаруженные параметры имеют значение `null`. Сайт не должен выдумывать отсутствующие технические данные.

## Использование с ESP32

После появления API ESP32 внешний сайт сможет сравнить, например:

```json
{
  "slots": 24,
  "rpm": 3000,
  "phases": 3
}
```

с индексом справочника и открыть подходящие страницы. Если найдено несколько вариантов, пользователь должен выбрать нужную схему вручную. Автоматическое решение допустимо только при однозначном совпадении критериев.

## Нагрузка

Формирование контекста выполняется в браузере после загрузки старой HTML-страницы. ESP32 в этом процессе не участвует, поэтому дополнительной нагрузки на контроллер нет.

## Ограничение

Контекст схемы является навигационным и интеграционным слоем. Он не заменяет исходную страницу, таблицу, изображения или техническое описание. Оригинальные данные остаются главным источником для проверки схемы.
