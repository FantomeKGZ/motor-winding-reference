# Специальные и многоскоростные схемы

## Назначение

Обычной классификации `звезда / треугольник` недостаточно для части двигателей. Поэтому во внешнем справочнике добавлен отдельный консервативный классификатор специальных схем.

Рабочий модуль:

`site/shared/js/special-scheme-classifier.js`

Он работает поверх уже найденных конкретных вариантов укладки и связанных страниц схем соединений. Исходные HTML-файлы и изображения не изменяются.

## Какие признаки распознаются

По явно встречающемуся тексту модуль умеет помечать:

- `dahlander` — схема Даландера;
- `two-speed` — двухскоростная схема;
- `three-speed` — трёхскоростная схема;
- `pole-changing` — переключение числа полюсов;
- `separate-windings` — раздельные обмотки;
- `double-star` — двойная звезда;
- `star-delta` — звезда/треугольник;
- `delta-double-star` — треугольник/двойная звезда;
- `switchable` — переключаемая схема.

Распознавание выполняется только по явным текстовым признакам в описании укладки, названии раздела, подсказках и метаданных связанных страниц соединений.

## Данные ESP32

Для будущего live API предусмотрены необязательные поля:

- `special_connection`;
- `speed_scheme`;
- `special_scheme`;
- `winding_switching`.

Предпочтительный основной вариант — `special_connection`.

Пример:

```json
{
  "motor": {
    "slots": 36,
    "rpm": 1500,
    "special_connection": "dahlander"
  }
}
```

## Правило безопасности сопоставления

Классификатор специально работает осторожно.

Если ESP32 передала специальный тип и у кандидата явно распознан другой специальный тип, такой кандидат можно скрыть как явно несовместимый.

Если у кандидата специальный тип вообще не удалось надёжно распознать, он не удаляется автоматически. Он остаётся для ручной проверки мастером.

Таким образом отсутствие текста в старом справочнике не превращается в ложное отрицательное совпадение.

## Интерфейс

У вариантов, где распознаны специальные признаки, появляется строка вида:

`Специальные признаки: Даландер, двухскоростная, переключение полюсов`

Если ESP32 передала конкретный специальный тип, панель также показывает:

- какой тип запрошен;
- сколько явно несовместимых вариантов скрыто;
- сколько вариантов осталось для проверки;
- предупреждение, что нераспознанные варианты не исключаются автоматически.

## Событие и данные JavaScript

После классификации доступен объект:

`window.CoilMasterSpecialSchemeResult`

и событие:

`coilmaster:special-scheme-result`

Объект содержит:

- `motor` — текущие данные двигателя;
- `wanted` — нормализованный специальный тип или `null`;
- `classified` — варианты вместе с распознанными тегами;
- `explicitMismatch` — число явно несовместимых вариантов.

## Что ещё предстоит

Текущий классификатор является текстовым и навигационным. Следующие этапы:

1. построить инвентаризацию всех страниц многоскоростных и специальных схем;
2. выделить устойчивые структурные признаки отдельных типов;
3. добавить отдельные тестовые примеры из реального справочника;
4. определить поля API ESP32 для скоростей, пар полюсов и режима переключения;
5. только после этого разрешать более строгую автоматическую фильтрацию.

Автоматически подтверждать электрическую схему только по слову «Даландер» или по имени файла нельзя.
